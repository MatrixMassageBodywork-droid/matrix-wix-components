# Pages

Each website page gets its own folder.

Recommended contents:

- `renderer.js` — portable page/body renderer or web component.
- `wix-page-code.js` — Wix-only page code when required.
- `README.md` — URL, Wix page ID, custom-element tag/ID, deployment notes, SEO preservation requirements, and known limitations.
- Optional assets/config files needed to recreate the page outside Wix.

GitHub is authoritative for code history. Wix is treated as a deployment target.
